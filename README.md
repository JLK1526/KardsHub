# KARDS · 二战卡牌模拟器

一个二战题材的集换式卡牌游戏。玩家选择一个国家阵营，与对手在三线战场上部署部队、争夺前线，先把敌方总部打到 0 点即可获胜。

游戏收录德国、美国、英国、苏联、日本五大阵营，各有一套风格鲜明的卡组，另有一个隐藏阵营等待发掘。支持经典与现代两种界面风格，配有军事题材音效和战斗特效。

---

## 快速上手

1. **选择阵营与难度**：开始界面右侧选国家（德 / 美 / 英 / 苏 / 日）和难度（低 / 中 / 高），点击「开始战斗」。
2. **部署部队**：点击手牌，再点击己方支援线的空位。带「空降」的单位可直接部署到前线。
3. **下达行动**：点击己方单位后，高亮的空位可直接推进，高亮的敌方目标可直接攻击，无需再点按钮。
4. **结束回合**：点右下「结束回合」，轮到对手行动。
5. **顶栏功能**：静音开关、重新开局、返回主菜单、切换界面风格。

## 战场规则

| # | 规则 | 说明 |
|---|---|---|
| 1 | 胜利条件 | 双方总部各 20 点防御（难度会调整对手总部血量）。先把敌方总部打至 0 点获胜，己方归零战败。 |
| 2 | 指挥点 | 每回合开始补满，且指挥点槽每回合 +1（上限 12）；回合结束未用完不保留。卡牌左上角大数字为部署费用，小数字为移动 / 攻击的行动费用。 |
| 3 | 三条战线 | 自上而下：敌方支援线（4 格）→ 前线（5 格）→ 己方支援线（4 格）。同一时间只有一方能控制前线。 |
| 4 | 部署 | 点击手牌再点空位部署；「空降」单位可直接进前线。 |
| 5 | 行动 | 单位每回合可移动一次、攻击一次，各消耗行动费。刚部署的单位需等下回合才能行动，除非拥有「闪击」。 |
| 6 | 进攻路线 | 所有单位都能攻击敌方前线单位。步兵 / 坦克必须先推进到前线，才能攻击敌方总部与支援线；火炮 / 战斗机 / 轰炸机是远程单位，留在己方支援线即可直接攻击敌方支援线与总部。「守护」单位必须被优先攻击。 |
| 7 | 交战 | 攻击时双方同时互相造成等同于自身攻击力的伤害，防御降至 0 即阵亡。支援线上的飞机只有空军 / 防空单位能攻击；地面单位无法对空反击；总部不会反击。 |
| 8 | 补给 | 每回合开始抽 1 张牌，手牌上限 9 张；牌库抽空后继续抽牌将受到逐次递增的疲劳伤害。 |

### 难度

| 难度 | 对手总部 | 特点 |
|---|---|---|
| 低（新兵演习） | 16 点 | 对手决策较随意，适合熟悉玩法 |
| 中（标准对局） | 20 点 | 平衡的标准对局 |
| 高（名将挑战） | 25 点 | 对手决策更精明，起始资源更多 |

## 阵营介绍

五大可选阵营，各有 12 种卡牌，按费用搭配组成 30 张牌库。

| 阵营 | 特色 |
|---|---|
| 德国 | 装甲集群 · 闪电战，高攻重装 |
| 美国 | 工业产能 · 空降，资源充裕 |
| 英国 | 坚壁防守 · 皇家空军，高防守护 |
| 苏联 | 钢铁洪流 · 纵深，冬季防御 |
| 日本 | 奇袭突击 · 海军航空，死战不退 |

**卡牌类型**：步兵、坦克、火炮、战斗机、轰炸机、指令。

**常见关键词**：
- **守护**：敌方必须优先攻击该单位
- **闪击**：部署当回合即可行动
- **空降**：直接部署到前线
- **对空 / 对坦克加成**：攻击特定目标时获得攻击力加成
- **防空**：可以攻击支援线上的敌方飞机

**隐藏阵营**：在界面上的「切换风格」按钮上，3 秒内连续点击 10 次，即可直接进入一局隐藏的「国民党」阵营对局。这套卡组主打持久抗战、德械精锐与美援空军。该阵营只在当局生效，不会影响正常的阵营选择。

## 界面与视听

- **两种风格**：经典模式贴近原版二战卡牌游戏画风，墨绿战场、旧纸卡面、黄铜金装饰；现代模式为深蓝暗调、毛玻璃面板与霓虹点缀。风格选择会被记住。
- **音效**：出牌、军靴踏地、枪声、火炮轰鸣、金属撞击、爆炸、总部中弹、无线电提示、胜利军号等，可在顶栏静音。
- **战斗特效**：曳光弹拖尾、命中冲击波、单位击毁爆炸、落地烟尘、推进轨迹、胜负演出，以及总部濒危警示。
- **操作体验**：点选单位即高亮所有合法目标，点高亮处直接执行，所见即所点。

## 关于本作

这是爱好者制作的模拟器，规则按经典二战卡牌玩法做了简化与自定义（六大阵营、隐藏阵营均为自设计内容），并非官方产品。音效为程序合成，质感偏电子合成而非真实录音。
